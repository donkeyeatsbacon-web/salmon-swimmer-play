# Salmon Swimmer — play in your browser

**Play:** https://donkeyeatsbacon-web.github.io/salmon-swimmer-play/

Guide a salmon upstream past currents, bears, eagles, fishing hooks and waterfalls to reach the spawning grounds.

- **Phone:** turn it sideways. Hold anywhere to swim up, let go to sink. Hit the surface fast to leap; in a waterfall, tap to jump again.
- **Computer:** hold the mouse button, Space or Up arrow. Escape or P pauses.

This repository only contains the exported web build (made with Godot 4.7).
